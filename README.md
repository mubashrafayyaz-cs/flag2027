# FLAG 2027 – Team FAST-Fair

Our code for the FLAG 2027 Grand Challenge (Face-voice Association across LAnguages and Gender, IEEE SPS Challenge Program).

The task is cross-modal verification: given a face image and a voice clip, decide whether they belong to the same person. Systems are tested on English (heard) and Bengali (unheard), in a standard and a gender-constrained setting.
